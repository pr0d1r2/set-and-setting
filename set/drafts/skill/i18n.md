# Skill: i18n

Skills can be translated to other natural languages, allowing agents
to operate with localized rule sets that may be more token-efficient
in non-English contexts.

## Rules

- Canonical skill language is English. Translations derive from
  English source.
- Translated skill path mirrors source:
  `skills/generic/skill.md` → `skills/generic/skill.ja.md`.
- Language suffix uses ISO 639-1 codes.
- Translation must preserve all rules — no rules dropped, no rules
  added. Semantic equivalence, not creative adaptation.
- When source skill updates, translations are marked stale until
  re-translated.
- Token efficiency varies by language and model — measure before
  assuming translation saves tokens.
