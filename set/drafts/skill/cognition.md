# Skill: cognition

Cross-cutting skills that enhance model reasoning rather than encode
domain rules. These skills improve how the agent thinks, not what it
knows about a specific topic.

## Patterns

- **Decomposition**: break complex tasks into independent subtasks
  before starting. Name each subtask.
- **Verification**: after producing output, verify it against input
  constraints before presenting.
- **Contradiction detection**: when two sources disagree, flag the
  conflict rather than silently picking one.
- **Scope awareness**: before acting, state what is in scope and what
  is explicitly out of scope.
- **Uncertainty signaling**: distinguish "I know X" from "X seems
  likely" from "I'm guessing X". Never present guesses as facts.
