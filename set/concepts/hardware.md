# Hardware

Hardware templates describe machine capabilities for development,
building, and testing. Each template is a standalone file under
`hardware/<vendor>/<model>.md`.

Consumer projects compose hardware into roles (dev host, builder,
test bench) in their own concepts — these templates describe what
a machine CAN do, not what role it fills.
