# AMD Ryzen 3700X

Ryzen 3700X (8 cores / 16 threads), 32 GB RAM (x86_64-linux).

## Capabilities

- Native x86_64-linux builds.
- Serves as nix remote builder for aarch64-darwin hosts.
- Runs QEMU with full KVM acceleration for x86_64-linux guests.
- Builds NixOS ISOs natively.
- Handles remote USB burns.
- Runs full integration test suites under QEMU.
- Storage: NVMe SSD (PCIe 4.0 x4) -- fast parallel builds.
