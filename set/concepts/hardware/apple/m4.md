# Apple M4

MacBook Air M4, 16 GB unified RAM (aarch64-darwin).

## Capabilities

- Native aarch64-darwin builds.
- Runs dev shell, editor, AI coding agents.
- Delegates heavy builds to remote builder via nix distributed builds.
- Cannot run x86_64-linux QEMU with full KVM — emulation only.
- Single-user nix install (macOS default).
