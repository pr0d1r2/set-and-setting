# Git repo: license

The project is MIT-licensed. The `LICENSE` file at the repo root is
the canonical copy.

## Implications for contributions

- All contributions are licensed under the same MIT terms.
- No CLA (Contributor License Agreement) is required.
- Third-party dependencies must have compatible licenses (MIT, BSD,
  Apache-2.0, ISC). GPL dependencies are not acceptable because they
  would require the entire project to be GPL.

## When adding dependencies

Check the license of any new nix package or vendored code. If the
license is not MIT-compatible, raise it before merging.
