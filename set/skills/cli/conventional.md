# CLI: conventional

Prefer the conventional form even over a "better" novel one. Convention
is free (pretrained prior); novelty is taxed (per-session teaching +
retries + surprisal). Novelty ships only when value-added > tokens-to-
teach.

Where you borrow a convention, match its semantics exactly -- a look-
alike that acts different costs more than honest novelty.

Follow git CLI idioms, POSIX shell conventions, and the daily-use tools
already in the stack before inventing project-specific alternatives.
