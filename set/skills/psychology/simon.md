# Autonomy: Simon effect

Choose an action from the task-relevant instruction, not from where a cue
appears. An irrelevant spatial cue can automatically activate a corresponding
response, making an incompatible response slower or more error-prone even
when location has nothing to do with the requested choice.

## Preserving autonomous action selection

- Define the response rule before inspecting the choices. State which property
  determines the action and which properties, especially position, order, and
  proximity, are irrelevant.
- Separate identity from location. Restate each option by its meaning, stable
  identifier, or observed behavior without words such as left, right, first,
  last, near, or far unless location is part of the rule.
- Pause when the relevant answer conflicts with the response suggested by its
  placement. Treat the extra fluency of a spatially compatible action as a cue
  to verify the rule, not as evidence for that action.
- Re-map the presentation and repeat the decision. Swap sides, randomize order,
  remove the default, or use a nonspatial representation; a task-relevant
  conclusion should survive changes to irrelevant placement.
- Verify consequential actions against the target. Before selecting, editing,
  approving, or deleting, name the intended object and compare its stable
  identity and state with the instruction.
- Design interfaces so placement supports rather than competes with the
  response rule. Keep mappings consistent, label controls directly, provide
  adequate spacing, and do not make a dangerous action the effortless spatial
  counterpart of a routine one.
- Measure the effect before attributing it. Compare accuracy and response time
  across compatible, incompatible, and neutral arrangements while holding the
  relevant stimulus and response rule constant.

## Signals of violation

- An option is selected because it is on the expected side even though its
  label, identity, or state calls for the other response.
- Reordering equivalent choices changes the decision without changing the
  task-relevant evidence.
- A nearby, first, or preselected control is treated as the agent's intent.
- A destructive action targets the spatially convenient object rather than the
  named object.
- An interface is blamed for a Simon effect without a compatible-versus-
  incompatible comparison or with location relevant to the task.

## Limits

The Simon effect concerns conflict between an irrelevant stimulus location and
a spatially corresponding response. It does not show that choices are never autonomous,
that every order or default effect has the same cause, or that
spatial information should always be ignored. Location may be task-relevant,
and practice, response design, accessibility needs, and timing can change the
effect. First resolve ambiguous instructions, mislabeled controls, motor
errors, and other plausible causes; use this model when an irrelevant location
competes with the required response.

Based on the [Simon effect](https://en.wikipedia.org/wiki/Simon_effect), in
which responses are generally faster and more accurate when an irrelevant
stimulus location corresponds with the response location.
