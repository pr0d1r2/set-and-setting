# Stroop effect

When cues conflict, identify and respond to the dimension the task actually
asks about. A familiar or salient cue can trigger an automatic response that
interferes with a less automatic one, even when the irrelevant cue is plainly
wrong.

## Countering cognitive interference

- State the target dimension before inspecting the evidence. Decide whether
  the task asks for actual behavior, a label, a value, a source, a status, or
  another attribute, and judge only that attribute.
- Separate conflicting cues. Read the value without its styling, inspect the
  implementation without its name or comment, and compare raw data apart from
  its summary when presentation pulls toward a different answer.
- Slow down when automatic and task-relevant responses disagree. Treat the
  first fluent answer as interference to check, not evidence that the requested
  answer changed.
- Name both observations precisely. Record what the distracting cue says and
  what the relevant cue shows instead of blending them into one impression.
- Verify the relevant dimension through an independent representation. Query
  the underlying state, run the behavior, or restate the instruction without
  the distracting cue.
- Design interfaces to reduce avoidable conflict. Keep labels, colors, icons,
  defaults, examples, and actual state consistent; when conflict is necessary,
  make the decision-bearing signal explicit and accessible without color alone.
- Measure interference when it matters. Compare accuracy and response time for
  aligned, neutral, and conflicting presentations before claiming that a cue
  helps or harms performance.

## Signals of violation

- A variable, test, button, or status is trusted because of its name or color
  even though its behavior or underlying state disagrees.
- A familiar label answers a different question from the one requested, and
  the mismatch passes unnoticed.
- Conflicting evidence causes repeated fast guesses instead of decomposition
  and independent verification.
- An interface uses decoration to convey one state while its text, control, or
  behavior conveys another.
- A presentation is called confusing without comparing it with a neutral or
  congruent condition.

## Limits

The Stroop effect demonstrates interference under particular attention tasks;
it does not prove that every mistake comes from automatic processing or that
slower responses are more accurate. Expertise, accessibility needs, language,
practice, and task design can change the size of the effect. First remove
ambiguity or bad data, then use this model when competing cues plausibly explain
the error.

Based on the [Stroop effect](https://en.wikipedia.org/wiki/Stroop_effect), in
which naming a stimulus attribute takes longer and is more error-prone when an
automatic reading response supplies a conflicting answer.
