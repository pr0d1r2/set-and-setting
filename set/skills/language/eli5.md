# Language: ELI5

Prefer simple language that any reader can follow without
domain expertise. When a concept has a plain-English equivalent,
use it. When jargon is unavoidable, define it immediately in
the same sentence or a parenthetical.

## Rules

- Short words over long: "use" not "utilize", "end" not
  "terminate", "show" not "demonstrate".
- One idea per sentence. If a sentence needs a semicolon or
  three commas, split it.
- Concrete over abstract: "the file is copied" not "the
  artifact is transitioned to the target context".
- Analogies help. Compare unfamiliar concepts to everyday
  objects when accuracy allows.
- Avoid acronyms on first use. Write the full term, then
  the acronym in parentheses: "Continuous Integration (CI)".
  After that, the acronym is fine.
- No assumptions about the reader's background. A sentence
  that only makes sense if you already know the answer is
  not an explanation.
- Test your explanation: if removing all technical terms
  leaves the meaning intact, the original was clear enough.
  If it collapses, simplify.
